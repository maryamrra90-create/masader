    Traceability matrix¶

    Status values: Completed (built as designed and tested), Modified (built differently from v1.2; the deviation id says why), Partial (built, but part of it is missing or not exercised), Simulated (the code path exists; the evidence comes from a stand-in, not the real service), Not built (stage 2 or out of scope). Evidence points to code, tests (tests/...::name) and measured results (eval/results/*.json). Scoring against the proposal's success criteria M1–M10 is in the implementation report, Section 2.1.
